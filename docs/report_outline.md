# FORE448 report outline — 5–8 pages

This is an outline, not a completed scientific report. Insert only measured results after processing and manual validation.

1. **Introduction and forestry question (0.5–1 page).** Cyclone Gabrielle, Esk pilot, plantation/native context and the structural-disturbance research question.
2. **Data and timing (1 page).** AOI map, actual selected dates/scene IDs/orbits, optional LiDAR tile date ranges if used, source resolution and common coverage. Explain delayed LiDAR and pre-event forest-mask age.
3. **Methods (1–1.5 pages).** Optional native CHM/cover where available, consistent RTC, optical QA, grid alignment, registration assessment, stable-reference calibration, five signature rules and sample design.
4. **Results (1.5–2 pages).** Fused map plus concise LiDAR/SAR/optical comparison, measured height/cover change only if LiDAR is used, and mapped area by forest type, signature and slope. Distinguish mapped areas from accuracy-adjusted estimates.
5. **Validation and sensitivity (1 page).** Manual LINZ evidence, weighted matrix/metrics with class support, uncertain cases and threshold sensitivity. Show correct, incorrect and ambiguous examples with image dates.
6. **Discussion and management implications (1–1.5 pages).** Temporal mismatch, harvesting, moisture, sediment, cloud/terrain effects, mixed pixels and limitations for operational forest assessment. No exclusive cyclone attribution from multi-year CHM changes.
7. **Conclusion and references (0.5 page).** Answer the forestry question at the supported scale. Cite LINZ, HBRC, LCDB, ASF/NASA, ESA/USGS and the exact software/inventory version.
